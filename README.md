# HR Analytics Project

## 📌 Overview
This project analyzes employee attrition data to identify factors affecting employee retention.

## 🛠️ Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Analysis Performed
- Attrition Analysis
- Overtime vs Attrition
- Salary vs Attrition
- Age vs Attrition
- Department-wise Attrition

## 💡 Key Insights
- Overtime employees leave more
- Low salary employees show higher attrition
- Younger employees leave more frequently
- Sales department has higher attrition

## 🚀 Conclusion
The project helps understand employee attrition patterns and supports HR decision-making.

## 📎 Dataset
IBM HR Analytics Dataset from Kaggle
